# Nublix — Assets vectorizados (Píxel)

Todo el contenido es SVG editable (escalable sin pérdida de calidad, y editable en Illustrator/Figma/código).

## /logo
- `logotipo.svg` / `logotipo-negativo.svg` — solo el wordmark "nublix"
- `isotipo-a-nodo.svg` — símbolo N-nodo
- `isotipo-b-cursor.svg` / `isotipo-b-cursor-claro.svg` — símbolo ">n" (uso como favicon/app icon)
- `imagotipo.svg` / `imagotipo-negativo.svg` — símbolo A + wordmark
- `isologo.svg` / `isologo-claro.svg` — emblema fusionado (símbolo B + nombre)
- `favicon.svg` — copia del isotipo B lista para usar como favicon

## /visual-assets
- `patron-pixel.svg` — patrón repetible (incluye `<pattern id="nublixPixelPattern">` reutilizable en CSS/SVG)
- `iconos/` — 6 iconos de línea: dashboard, cloud, automatizacion, conexion, crecimiento, codigo
- `formas.svg` — hoja de formas sueltas para decorar secciones
- `textura-puntos-clara.svg` / `textura-puntos-oscura.svg` — texturas de fondo tipo grid de puntos
- `bloques-color.svg` — bloques y degradado para fondos de sección
- `ui-componentes.svg` — botón, chip y barra de progreso de referencia

## /tokens
- `colores.css` — variables CSS con los colores y tipografías de marca

## Nota sobre la tipografía
Los textos usan Space Grotesk / Space Mono vía `font-family`. Si vais a insertar estos SVG directamente en la web, cargad esas fuentes con Google Fonts para que el texto se vea correcto; si las abrís en Illustrator/Figma sin la fuente instalada, el texto puede mostrarse con una fuente de sistema — convertidlo a trazado antes de imprimir.
